# Zink WinUI-to-Slint page parity audit

Updated: 2026-11-09

This audit compares the 99 non-generated XAML surfaces in the original WinUI project with the Rust/Slint application. A route being present does **not** mean its design or feature implementation is complete.

## Status definitions

- **Implemented**: dedicated Slint page exists and its principal local controls are connected to Rust code.
- **Partial**: dedicated Slint design exists, but one or more original integrations or commands remain unavailable.
- **Route only**: the sidebar entry loads, but currently shows the migration-gated page instead of a faithful copy.
- **Window missing**: the original used a separate window and no equivalent Rust window exists yet.

## Remaining runtime validation and native work

- FPS Recorder requires final live RTSS compatibility validation across supported games and overlays.
- Zink Social calling and screen sharing require cross-device runtime validation against the existing server.
- Streaming provider pages, native source preview, selectable Windows audio endpoints and Twitch live telemetry are implemented; the original embedded Twitch OAuth/overlay window remains.
- Background Recording Settings and Recorder now use the Zink-owned rolling replay implementation; selectable render/capture audio endpoints and live hardware validation remain.

## Separate-window parity still missing

- No source-level auxiliary-window gaps are currently recorded; each separate window still requires final packaged-build runtime verification.

## Navigation verification

- The Release build was launched on Windows.
- The expanded sidebar was visually verified to scroll beyond the initial viewport.
- A newly added route (`TV`) was selected and verified to load its migration-gated page.
- Slint currently exposes only the native window chrome through Windows UI Automation, so button-by-button automated accessibility verification is not yet available. Native Rust callback tests and live visual checks are required until accessibility peers are added.
